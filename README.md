# Principal Component Analysis (PCA) Project
**Mathematics and Statistics for AI**

## Project Overview
This project explores the application of **Principal Component Analysis (PCA)** for **dimensionality reduction** using a dataset of images. Each image is treated as a single observation, where each pixel represents a variable. The project focuses on analyzing the covariance structure of the data, extracting principal components, and visualizing the reduced feature space to better understand patterns and similarities among images.

The work emphasizes both **conceptual understanding** of PCA and its **practical implementation in Python**.

---

## Objectives
- Understand the mathematical foundations of Principal Component Analysis  
- Analyze high-dimensional image data using covariance matrices and eigen decomposition  
- Apply dimensionality reduction techniques  
- Evaluate image reconstruction quality using different numbers of principal components  

---

## Project Tasks
1. Load the provided dataset and image files.
2. Flatten each image into a single row vector, where each pixel represents a variable.
3. Compute the covariance matrix of the dataset.
4. Calculate the eigenvalues and eigenvectors of the covariance matrix.
5. Identify and interpret the top eigenvalues and their corresponding eigenvectors (principal components).
6. Reduce the dataset to **2 principal components** using PCA and visualize the images in the reduced space.
7. Reconstruct the original images using **2, 5, 10, 20, and 30** principal components.
8. Compare the reconstruction quality across different numbers of components.
9. Discuss whether increasing the number of principal components improves the quality of the reconstructed images.
