# Principal Component Analysis (PCA) Project
Mathematics and Statistics for AI Course

Project Description:
In this project, students will explore the application of Principal Component Analysis (PCA) for dimensionality reduction using the provided dataset and image files. Each image represents an observation and each pixel represents a variable. Students will analyze the covariance structure of the data, extract the principal components, and visualize the reduced dimensions to understand the structure and similarity among images. The project emphasizes both conceptual understanding and practical implementation in Python.

Project Requirements:
1. Load the provided dataset and image files from Moodle.
2. Flatten each image into a single row vector (each pixel is a variable).
3. Compute the covariance matrix of the dataset.
4. Compute eigenvalues and eigenvectors of the covariance matrix.
5. List and interpret the top eigenvalues and their corresponding eigenvectors (principal components).
6. Perform dimensionality reduction using PCA to 2 components and visualize the images in the new space.
7. Reconstruct the original images using 2, 5, 10, 20, and 30 principal components, and compare reconstruction quality.
8. Discuss whether using more principal components improves the quality of reconstructed images.
9. Submit the following items on Moodle:
   
   • Python notebook (.ipynb) with clear documentation and comments.
   
   • A written report (2–3 pages, excluding cover page).
   
   • A 10-minute oral presentation demonstrating results and explaining findings.
